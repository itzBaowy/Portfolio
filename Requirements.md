3D phải:

Nếu 3D làm giảm trải nghiệm trên điện thoại, hãy thay bằng ảnh render tĩnh hoặc một phiên bản CSS nhẹ.

# 18. PERFORMANCE OPTIMIZATION

Website phải hoạt động mượt trên thiết bị phổ thông.

Mục tiêu Lighthouse cho các trang chính trong môi trường production:

- Performance: >= 90 nếu khả thi
- Accessibility: >= 95
- Best Practices: >= 95
- SEO: >= 95

Mục tiêu Core Web Vitals:

- LCP <= 2.5s
- CLS <= 0.1
- INP <= 200ms

Đây là mục tiêu cần đo đạc, không phải kết quả được phép tự tuyên bố.

Áp dụng:

- Dynamic import cho Three.js
- Lazy loading
- next/image khi tương thích
- next/font
- Font optimization
- Tree shaking
- Static generation
- Prefetch hợp lý
- Code splitting
- Giảm JavaScript không cần thiết
- Tránh hydration mismatch
- Tối ưu ảnh và video

Không sử dụng video nền quá nặng.
